# Property Rental Management

Business management application built with React, TypeScript, FastAPI and
PostgreSQL.

## Status

Planning and initial architecture stage.

## Main components

- `frontend/` — React and TypeScript user interface
- `backend/` — FastAPI application and business logic
- `docs/` — requirements, architecture and business documentation
- `scripts/` — development and maintenance utilities
- `compose.yaml` — local development services

## Prerequisites

- Git
- Node.js
- Python
- Docker Desktop
- Docker Compose
- VS Code

## Setup

Setup instructions will be added after the frontend, backend and database
projects are initialized.

## Development workflow

1. Create or select a Git branch.
2. Review the relevant requirements and business rules.
3. Prepare an implementation plan.
4. Implement a focused change.
5. Run tests, type checks and builds.
6. Review the diff.
7. Commit only verified work.

## Security

Do not commit:

- `.env`
- Passwords
- API keys
- Database credentials
- Customer information
- Production database backups
