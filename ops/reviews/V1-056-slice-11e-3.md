## Review round 1 (one read-only agent)

No blocker. The argument order of every command and every answer check against the real draft
shapes were confirmed.

- S1 (fixed): a new receipt into a Reservation Deposit or a Deposit of another Lease that is not
  terminated answered a wrong code; both messages now answer 422
  `RECEIPT_CORRECTION_DEPOSIT_NOT_OF_LEASE` on `receipts`. The unreachable Deposit-not-found code
  on `steps` was removed.
- S2 (fixed): an inactive or unknown Refund method answers on the field that named it:
  `CORRECTION_REFUND_METHOD_OFF` on `refund_method_id`, `CORRECTION_NEW_REFUND_METHOD_OFF` on
  `new_refund_method_id`, or the Final Settlement code on `steps` where only a step names it.
- S3 (fixed): `returned_at` uses the project `Instant` type (an explicit RFC3339 text with its
  offset; a number or a space separator is refused).
- S4 (fixed): two receipts into one Deposit, or a plan with no new receipt, answer 422 on
  `receipts` before any command.
- Nits fixed: the outside-Settlement overlay is 409 with no field; only the two Final Settlement
  state messages these paths raise are named; the return date and forfeiture texts; the docs text
  limits; the module docstring; the traceability notes.
- Left as is: "A return reversal brings back only the returned amount" stays a plain 409 (an
  internal fail-closed check).
