# Security

## Secrets

- Store secrets in environment variables.
- Never commit `.env`.
- Rotate credentials after accidental disclosure.

## Authorization

## Personal data

- Collect only necessary information.
- Restrict access according to role.
- Avoid placing personal data in logs.
- Define retention and deletion procedures.

## Database

- Use least-privilege database credentials.
- Back up regularly.
- Test restoration procedures.
- Encrypt production traffic.

## Dependency security

- Keep dependencies maintained.
- Review new packages before installation.
- Run dependency vulnerability checks.
